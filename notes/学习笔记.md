### 一轮循环（学员口述 · 精炼版）

> 用户提问 → 请求 LLM → 输出 `Thought` + `Action`（或 `Final Answer`）→ **程序**执行 `simulate_tool` 得 `Observation` → 追加到 `scratchpad` → 再请求 LLM → 重复，直到 `Final Answer` 或 `max_steps`。

**关键纠正**：Action 是模型「点菜」，不是模型自己调函数；Observation 才是工具结果。

### 核心函数

| 函数 | 作用 |
|------|------|
| `parse_react(text)` | 正则拆 `Thought` / `Action` / `Final Answer` |
| `parse_action(line)` | `get_weather[广州]` → `("get_weather", "广州")` |
| `simulate_tool(name, arg)` | 查 `FAKE_TOOL_RESULTS`；`calculator` 可 `eval` 兜底 |
| `run_react(question, max_steps)` | 主循环 + scratchpad 累加 |

### scratchpad 是什么

每轮把 `Thought / Action / Observation` 拼成字符串，下一轮塞进 user 消息，让模型「看见」之前做过什么——类似 D12 的 messages 历史，但是 ReAct 专用格式。

### 正则表达式（当日新知）

**正则 = 文本模式匹配 + 提取工具**。例：`^(\w+)\[(.+)\]$` 从 `calculator[(3+5)*2]` 抓工具名和完整参数。

符号速记：`\w+` 单词字符；`(.+)` 分组抓取；`^` `$` 首尾；`re.match` 从开头匹配。

### 踩坑记录

旧正则 `[^\]]+` 在嵌套括号处截断，变成 `(3+5)` 丢了 `*2`。

### 力扣 · 242 有效的字母异位词 ✅

题意：两字符串字母组成是否相同（顺序无关）。练点：**Counter**（承接 D20 350）。

```python
from collections import Counter

class Solution:
    def isAnagram(self, s: str, t: str) -> bool:
        return Counter(s) == Counter(t)
        # 或：return sorted(s) == sorted(t)
```

| 写法 | 要点 |
|------|------|
| `Counter(s) == Counter(t)` | 比频次，O(n)，推荐 |
| `sorted(s) == sorted(t)` | 排序后比，O(n log n) |
| `Counter(s).sort()` | ❌ Counter 无 `.sort()`；`.sort()` 只属于 list |

补充：`s.count("a")` 查单个；`Counter(s)` 查全部频次。

### 力扣 · 350 两个数组的交集 II

题意：返回交集，**保留重复次数**（349 只去重）。

**解法 1 · Counter（当日提交）**
```python
from collections import Counter

class Solution:
    def intersect(self, nums1: list[int], nums2: list[int]) -> list[int]:
        n1 = Counter(nums1)
        n2 = Counter(nums2)
        ans = []
        for x in n1:
            if x in n2:
                k = min(n1[x], n2[x])   # 两边都出现，取较少次数
                for _ in range(k):
                    ans.append(x)
        return ans
```

**解法 1b · Counter `&`（一行）**
```python
return list((Counter(nums1) & Counter(nums2)).elements())
```
- `Counter & Counter` 对每键取较小次数；`.elements()` 展开
- 记法：349 用 `set &`（去重），350 用 `Counter &`（保留次数）

**解法 2 · 排序 + 双指针（省空间 / 进阶答案）**
```python
class Solution:
    def intersect(self, nums1: list[int], nums2: list[int]) -> list[int]:
        nums1.sort(); nums2.sort()
        i = j = 0
        ans = []
        while i < len(nums1) and j < len(nums2):
            if nums1[i] < nums2[j]:
                i += 1
            elif nums1[i] > nums2[j]:
                j += 1
            else:
                ans.append(nums1[i]); i += 1; j += 1
        return ans
```

**解法 3 · 手动字典（理解 Counter 内部）**
```python
class Solution:
    def intersect(self, nums1: list[int], nums2: list[int]) -> list[int]:
        freq = {}
        for x in nums1:
            freq[x] = freq.get(x, 0) + 1
        ans = []
        for x in nums2:
            if freq.get(x, 0) > 0:
                ans.append(x)
                freq[x] -= 1
        return ans
```

| 解法 | 关键 | 适用 |
|------|------|------|
| Counter | 频次取 `min` | 最直观，首选 |
| 排序+双指针 | 相等才收 | 省空间 / 已排序 / 进阶 |
| 手动字典 | `get(x,0)` 配额 | 理解 Counter 内部 |

**Counter 用法速记**：`Counter(nums)` 统计频次；`c[x]` 取次数（无则 0）；`x in c` 判键；`c1 & c2` 取较小次数。

### 力扣 · 349 两个数组的交集

题意：返回两个数组的交集（结果去重）。练点：**set 交集 + O(1) 查找**。

**演进过程（3 版）**

```python
# ① list 查找版（能过但慢）：x in nums2 是 O(m)
cnt = []
for x in nums1:
    if x in nums2:
        cnt.append(x)
return set(cnt)          # 返回类型建议 list

# ② 半 set 版：查找仍在 list 里
seen = set()
for x in nums1:
    if x in nums2:
        seen.add(x)
return list(seen)

# ③ 双 set 标准版（最终提交）
s1 = set(nums1)
s2 = set(nums2)
cnt = []
for x in s1:
    if x in s2:
        cnt.append(x)
return cnt
```

一行版（记忆）：`return list(set(nums1) & set(nums2))`；`&` 交集、`|` 并集、`-` 差集。

**教训**：大量 `in` 判断前先转 set（同 D11 力扣 217 超时教训）。  
**AC** = Accepted（全部用例通过）；其他状态：Wrong Answer / TLE 超时 / Runtime Error。

### Agent 定义（口述精炼）

> Agent 是拥有**感知、推理、决策、执行**能力的 AI 代理：给定目标后，会思考并规划流程，必要时调用工具，感知执行结果与外部知识，判断是否已是最终输出；若否，则继续「思考 → 执行 → 感知」循环，直到完成任务。  
> 真正执行工具的是**程序**；LLM 负责推理与决策（点菜）。

### 四步循环

| 步 | 含义 | Phase 1 对应 |
|----|------|--------------|
| 感知 Perceive | 用户输入、工具结果、文档/知识库 | messages、`role:tool`、RAG 片段 |

### 力扣 · 136 只出现一次的数字

题意：其余元素都出现 **2 次**，找出只出现 **1 次**的。例：`[4,1,2,1,2]` → `4`  
题面进阶要求：时间 O(n)、额外空间 O(1) → 只有 **异或** 完全满足。

**① 手写字典计数（学员已写）** · 时间 O(n) · 空间 O(n)

```python
cnt = {}
for n in nums:
    if n in cnt:
        cnt[n] += 1
    else:
        cnt[n] = 1
    # 或：cnt[n] = cnt.get(n, 0) + 1
for n, v in cnt.items():
    if v == 1:
        return n
```

注意：变量别叫 `dict`（会盖住内置类型）。

**② Counter** · 时间 O(n) · 空间 O(n)

```python
from collections import Counter

for x, v in Counter(nums).items():
    if v == 1:
        return x
```

**③ set：遇见就加，再遇见就删** · 时间 O(n) · 空间 O(n)

```python
s = set()
for n in nums:
    if n in s:
        s.remove(n)
    else:
        s.add(n)
return s.pop()
```

成对数字加减抵消，最后 set 里只剩出现一次的。

**④ set + 数学** · 时间 O(n) · 空间 O(n)

```python
return 2 * sum(set(nums)) - sum(nums)
```

若每个数都出现两次：`2 * 不重复之和 == 全部之和`；差值就是只出现一次的那个。

**⑤ 异或（满足题面 O(1) 空间）** · 时间 O(n) · 空间 O(1)

性质：`a ^ a = 0`，`a ^ 0 = a`，异或满足交换律/结合律。

```python
ans = 0
for n in nums:
    ans ^= n
return ans
# 或：return functools.reduce(operator.xor, nums)
```

`[4,1,2,1,2]` → `0^4^1^2^1^2` → 成对变 0 → 剩 `4`。

| 解法 | 好懂？ | 满足「常量额外空间」？ |
|------|--------|------------------------|
| 字典 / Counter | ⭐⭐⭐ | ❌ |
| set 加减 / 数学 | ⭐⭐ | ❌ |
| 异或 | ⭐（要记性质） | ✅ |

## 环境踩坑 · Cursor 终端拖动重绘（2026-07-16）

**现象**

- 在 Cursor 内置终端跑交互脚本（如 `tool_chat.py`）时，**拖动终端高度**或 **Ctrl+J 显隐面板**后：
  - 输出重复（同一句 AI 回答刷多遍）
  - 看起来像程序「自己重启」、夹杂假的 `Activate.ps1`
  - 半截乱码
- **同一 pid、同一秒时间戳**仍反复出现 → 不是 Python 真重启，是显示层把旧内容画多遍
- **外部 Windows PowerShell 完全正常** → 代码没问题

**原因**

- Cursor/VS Code 在 Windows 上用 ConPTY；终端 **resize/reflow** 时有已知重绘 bug
- 相关：vscode#308519、vscode#267477

**解决办法（已写入 Cursor User settings）**

```json
"terminal.integrated.windowsUseConptyDll": true,
"terminal.integrated.gpuAcceleration": "auto"
```

| 设置 | 作用 |
|------|------|
| **`windowsUseConptyDll: true`** | **关键**：减轻拖动/显隐时的重复重绘 |
| `gpuAcceleration: "auto"` | 拖动更顺；若设成 `"off"` 可再压重绘，但拖终端会明显卡 |

**使用建议**

1. 跑 `input()` 长会话时尽量先调好终端大小，中途少拖、少 Ctrl+J  
2. 仍异常 → 用外部 PowerShell 跑脚本做验收  
3. 设置文件：`%APPDATA%\Cursor\User\settings.json`

### 力扣 · 合并两个有序数组

```python
class Solution(object):
    def merge(self, nums1, m, nums2, n):
        i = m - 1
        j = n - 1
        k = m + n - 1
        while i >= 0 and j >= 0:
            if nums1[i] > nums2[j]:
                nums1[k] = nums1[i]
                i -= 1
            else:
                nums1[k] = nums2[j]
                j -= 1
            k -= 1
        while j >= 0:
            nums1[k] = nums2[j]
            j -= 1
            k -= 1
```

- `m`=nums1 有效个数；`n`=nums2 个数=预留空位个数（题设）；`len(nums1)=m+n`
- 下标从 0 起：`i=m-1` 指向最后一个有效元，不是 `m`
- 比较循环必须 `and`，避免一边耗尽后越界

```python
class Solution(object):
    def moveZeroes(self, nums):
        i = 0
        for n in range(len(nums)):
            if nums[n] != 0:
                nums[i], nums[n] = nums[n], nums[i]
                i += 1
```

### 力扣 · 有效的括号
- 链接：[20. 有效的括号](https://leetcode.cn/problems/valid-parentheses/)
- 思路：列表当栈；左括号 `append` 入栈；右括号先判栈空 → 再判栈顶是否配对 → `pop`
- 模板：`遇到左括号入栈 / 遇到右括号不匹配或栈空则 False / 扫完 return not stack`
- 坑：① 循环内匹配成功就 `return True`（应继续扫）② 忘 `if not stack` ③ `false` 应写 `False`

```python
class Solution:
    def isValid(self, s: str) -> bool:
        stack = []
        for i in s:
            if i in '([{':
                stack.append(i)
            elif i in ')]}':
                if not stack:
                    return False
                if i == ')' and stack[-1] != '(':
                    return False
                if i == ']' and stack[-1] != '[':
                    return False
                if i == '}' and stack[-1] != '{':
                    return False
                stack.pop()
        return not stack
```

### 力扣复习 · 两数之和 dict 一遍解
- 链接：[1. 两数之和](https://leetcode.cn/problems/two-sum/)
- `enumerate(nums)`：同时拿 `(下标, 元素)`
- `seen[n] = i`：字典记录「数值 n 出现在下标 i」
- 先查 `need in seen`，再 `seen[n] = i`；O(n) 时间

```python
class Solution:
    def twoSum(self, nums: list[int], target: int) -> list[int]:
        seen = {}
        for i, n in enumerate(nums):
            need = target - n
            if need in seen:
                return [seen[need], i]
            seen[n] = i
        return []
```

### 我自己的理解（D9）

1. **想让模型 / Agent 在某一类任务上表现稳定时**，应在 Prompt 的 `system` 里写清角色、输出格式和约束；`user` 放本次要处理的具体内容。不只 Agent 才这样，所有 Chat Completions 都适用。

2. **有明确格式要求时，必须写进 `system`（或 `user` 里反复强调）**，不能只指望调低 `temperature` 让模型「自觉听话」。

   - 正确做法：**Prompt 约束格式 + 必要时低 temperature**，两者配合，不能互相替代

### AI 指南 · 关键结论（第 1 章原文笔记）
Agent核心概念：
1.大模型是Agent的大脑，不同的模型拥有不同的参数规模、对话上限和处理能力
2.prompt(提示词)输入的质量决定Agent输出的质量，分为系统提示词和用户提示词，前者要提前设置约束Agent，后者自主输入
3.Token可以看作网络世界的价值单位，Token越多，成本越高，输出速度慢
4.API key:你在每个大模型创建的钱包
5.模型蒸馏：大模型难部署，将大模型知识浓缩转移到小模型，保持大模型性能，降低推理成本
6.解析上下文，获取更多的输出依据
7.RAG检索增强：提供外部知识库为Agent补充知识，其中用到Embedding嵌入
8.工具调用使Agent能力边界和应用范围无限扩大
9.CoT(思维链)和ReAct技术：一个将思考推理过程透明化，一个将思考->计划->推理->执行->推理流程循环化
10.智能体工作流：多Agent协同
11.MCP(模型上下文协议)统一Agent调用工具接口的标准
2. 第 2 章：市面上的Agent有很多，它们作用于不同的领域，我们只需按需取用
3. 第 3 章：使用Agent有很多技巧，学习技巧有助于我们更快更好地完成任务

### Agent 路线 · 5 个术语（已理解）

| 术语 | 一句话 |
|------|--------|
| **ReAct** | 推理→行动→观察 循环，Agent 最经典架构 |
| **Function Calling** | 模型输出 JSON 调用函数，程序执行后回传结果 |
| **Reflection** | 执行后自我审视，发现错误再迭代 |
| **Multi-Agent** | 多个 Agent 分工协作完成复杂任务 |
| **Execute** | Plan-and-Execute 中「执行计划」的阶段 |

### 什么是 Agent ✅

> Agent 是基于 LLM 的智能应用系统，能感知、推理、自主决策、执行命令。  
> **聊天机器人**：只会说，不会做。  
> **Agent**：会说也会做——思考、计划、调用工具、反思记忆、迭代优化。
