## D7 · API / 环境（入门）

**题 1**  
`load_dotenv()` 之后，`os.getenv("DEEPSEEK_API_KEY")` 取到的值最可能来自哪里？

- A. `chat.py` 里写死的字符串  
- B. `.env` 文件里的配置  
- C. DeepSeek 服务器返回的 JSON  
- D. `requests.post` 的响应头  

**答案：B** — `load_dotenv` 把 `.env` 加载进环境变量；`os.getenv` 再读取。

**题 2**  
`response.raise_for_status()` 在什么时候会抛异常？

- A. `response.json()` 解析失败时  
- B. HTTP 状态码不是 2xx（如 401、404）时  
- C. 网络超时时  
- D. API Key 写错时（无论状态码）  

**答案：B** — 只检查 HTTP 是否 2xx；超时在 `post` 阶段；JSON 失败是 `.json()` 的事。

**Q1：** 为什么说大模型「本身没有记忆」，但多轮聊天又能记得你叫什么？  
→ 模型两次请求间不保存状态；「记得」是程序用 `messages` 把历史整段再发给 API。

→ 控 token；system 是整场角色规矩，丢掉会行为漂移。

## D13→D14 · Git 口述 + FC / RAG ✅

### Git（D13 开场口述）
