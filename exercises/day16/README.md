## 核心一句话

| 概念 | 一句话 |
|------|--------|
| **幻觉** | 模型凭训练记忆瞎编，听起来像真的 |
| **Embedding** | 把文字变成一串数字（向量），语义相近 → 数字也相近 |
| **相似度** | 两个向量有多「像」（常用余弦相似度） |
| **向量库** | 存这些向量，按相似度快速找出相关片段（Chroma / FAISS 等） |
| **RAG** | Retrieval-Augmented Generation：先检索相关片段，再塞进 Prompt 让模型答 |

**RAG 解决什么问题？**  
模型不知道你的私有文档 / 最新资料 → 容易胡编。先把「相关原文」塞给它，再让它基于原文回答。

---

## 五步流程（必须能口述）

```
① 准备文档 → 切成小块（chunk）
② 每块做 Embedding → 得到向量 → 存进向量库
③ 用户提问 → 问题也做成向量
④ 在向量库里找「最像」的几块（top-k）
⑤ 把这几块 + 问题一起塞进 Prompt → LLM 生成回答
```

对照图：`notes/diagrams/day16-rag-flow.md`（先自己画，再对照）。

## 和「直接拼 Prompt」的差别（为 D17 铺垫）

| 方式 | 做法 | 局限 |
|------|------|------|
| **拼 Prompt** | 整份文档塞进 messages | 文档一长就爆上下文；噪声多 |
| **RAG** | 只塞最相关的几块 | 检索错了也会答偏；需调 chunk / top-k |

今天先建立直觉；明天用代码体验「拼 Prompt」。

## 零代码体验（二选一即可）

### 方案 A：Dify（推荐，界面清晰）

1. 打开 [https://cloud.dify.ai](https://cloud.dify.ai)（或自建，有账号即可）
2. 创建 **知识库** → 上传 `sample_kb.md`（本目录）
3. 创建 **聊天助手** 应用 → 关联该知识库
4. 问：`学习计划一共多少天？` / `Phase 1 学什么？`
5. 看回答是否引用了文档内容（有的产品会显示引用片段）

### 方案 B：阿里云百炼知识库

1. 打开百炼控制台 → 应用 / 知识库相关入口
2. 上传 `sample_kb.md`，创建问答应用
3. 用同上两个问题自测

**体验时记下 3 点（写进笔记）：**
1. 上传了什么、问了什么、答得对不对
2. 关掉知识库再问同一题，回答有何不同（若界面支持）
3. 用自己的话写：**RAG 解决什么问题？**

## 拓展（时间够再看名词即可）

| 名词 | 是什么 |
|------|--------|
| **Chroma** | 常用本地向量库，Python 好装 |
| **FAISS** | Meta 开源的向量检索库，偏高性能 |
| **chunk_size** | 切块多大；太大噪声多，太小缺上下文 |
| **top-k** | 检索返回最相似的 k 条 |

D31 会真调 Embedding + Chroma；今天只知道「向量库是存向量、按相似度查」即可。
