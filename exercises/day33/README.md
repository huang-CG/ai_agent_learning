## 概念（先口述，再写代码）

### 1) Hybrid Search（混合检索）

| 方式 | 靠什么找 | 擅长 |
|------|----------|------|
| 向量检索 | Embedding 相似度 | 语义相近（换说法也能中） |
| 关键词检索（如 BM25） | 字面匹配 | 专有名词、编号、精确词 |
| **Hybrid** | 两者融合再排序 | 兼顾语义 + 精确词 |

今天**不要求实现** Hybrid；能说清「为什么要混合」即可。实现可留到以后或换稳定向量库后再做。

### 2) metadata 过滤

切块时给每段挂上字段，例如 `source` / `chunk_id` / `topic`。  
检索时可先（或同时）按字段缩小范围：只查 `topic=rules`，躲开「番茄炒蛋」干扰段。
