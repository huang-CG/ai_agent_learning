## 三种模式（先抓住流程）

### 1. ReAct（你已会）

```text
Thought → Action → Observation → Thought → … → Final Answer
```

- **边想边做**：一步工具、看结果、再决定下一步  
- 适合：工具结果会改变下一步（查天气、搜索、算一步再决定）  
- 你已做：D19–D23

### 2. Plan-and-Execute（计划再执行）

```text
① Planner：先写出多步计划（步骤 1、2、3…）
② Executor：按步骤执行（每步仍可调工具）
③（可选）重规划：某步失败或结果意外 → 改计划再继续
```

- **先拆任务，再干活**；执行中可调整  
- 适合：目标清晰、步骤可预见（「对比三城天气再推荐」「先查资料再写总结」）  
- 和 ReAct 比：少「走一步看一步」的盲目探索，多「总览」

### 3. Reflection（反思 / 自评再改）

```text
① 生成初稿（回答 / 代码 / 计划）
② Critic：按标准检查（错了吗？缺了吗？）
③ 根据反馈修改 → 可多轮，直到合格或达上限
```

- **做完再审、再改**；像写作用「自己当编辑」  
- 适合：质量敏感（文案、代码、长回答），工具调用不是唯一重点  
- 可和 ReAct / Plan 叠用：先执行，再反思结果

## 小例子（同一问题三种切法）

问题：「帮我决定周末去广州还是深圳玩，要看两地天气。」

| 模式 | 大致怎么走 |
|------|------------|
| **ReAct** | Thought→查广州天气→Observation→Thought→查深圳→再比较→Final |
| **Plan-and-Execute** | 计划：①查广州 ②查深圳 ③对比气温/降雨 ④给建议 → 再逐步执行 |
| **Reflection** | 先给一版建议 → 自检「是否两地都查了？有没有瞎编天气？」→ 不够就补查/改建议 |
