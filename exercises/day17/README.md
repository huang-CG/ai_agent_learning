# Day 17 · Phase 1 小项目：个人知识库 QA（拼 Prompt）

## 这题要你做什么？（一句话）

> **不用向量库**：把整份 markdown 读进字符串，塞进 Prompt，用 DeepSeek 对这份文档问答。然后对比「拼 Prompt」和昨天 Dify RAG 的局限。

验收：能对自己写的 markdown 文档问答 + Phase 1 复盘。

---

## 和 D16 RAG 的对比（今天要写进笔记）

| | **拼 Prompt（今天）** | **RAG（昨天 Dify / 将来 D32）** |
|--|----------------------|--------------------------------|
| 做法 | 整份文档塞进 messages | 只塞 top-k 相关片段 |
| 优点 | 实现极简单，小文档够用 | 文档很大也能用；噪声少 |
| 局限 | 文档一长就爆上下文；无关内容也占 token | 要 Embedding + 向量库；检索错会答偏 |

记忆：**小文档拼 Prompt；大文档才需要 RAG。**
