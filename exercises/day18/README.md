## 先抓住这一句

**Chatbot**：一问一答，主要靠嘴（生成文字）。  
**Agent**：有目标，能**多步行动**——想清楚 → 必要时调工具/查环境 → 看结果 → 再想再做，直到完成任务。

你已经会的零件，正好组成 Agent：

| Phase 1 学过 | 在 Agent 里像什么 |
|--------------|------------------|
| Prompt / CoT | **推理**（想） |
| Function Calling | **决策 + 执行工具**（点菜 + 程序做菜） |
| RAG / 拼文档 | **感知外部知识**（看资料） |
| 多轮 messages | **短期记忆**（记得刚才发生了什么） |

---

## 四步循环（必须能口述）

```
① 感知（Perceive）  ← 看输入：用户问题、工具返回、文档片段、传感器…
② 推理（Reason）    ← 想：现在情况怎样？差什么信息？
③ 决策（Decide）    ← 定：直接回答？还是调用哪个工具？
④ 执行（Act）       ← 干：调 API / 跑函数 / 检索… 得到 Observation
        ↓
   把结果当新感知，再进 ①（循环，直到能交卷）
```

对照图：`notes/diagrams/day18-agent-loop.md`（先自己画，再对照）。

**和 Function Calling 的关系**：FC 是「执行工具」那一环的技术实现；Agent = 在循环里**反复**推理 + 调工具，直到目标完成。

## Agent vs 普通 Chatbot（你要填进笔记的表）

先自己想，再对下面参考：

| 维度 | Chatbot | Agent |
|------|---------|--------|
| 目标 | 对话、回答问题 | 完成任务（可多步） |
| 是否用工具 | 通常不用（或很少） | 常用工具 / API / 代码 |
| 步数 | 多为单轮或闲聊多轮 | 可多轮 Thought→Action→观察 |
| 环境 | 主要是文字 | 可与外部世界交互 |
| 例子 | 客服话术机器人 | 「查天气再写出行建议」助手 |

## 1 分钟口述模板（验收用）

> Agent 是一个能**朝着目标行动**的 AI 系统：它先**感知**环境和输入，再**推理**当前该做什么，**决策**是直接答还是调用工具，然后**执行**并把结果拿回来继续循环，直到任务完成。  
> 普通 Chatbot 主要生成回复；Agent 还能用工具改变/获取外部信息。
