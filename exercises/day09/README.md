---

## 好 Prompt 的四要素

| 要素 | 含义 | 例子 |
|------|------|------|
| **角色** | 你是谁 | 「你是专业翻译」 |
| **任务** | 要干什么 | 「把下面中文译成英文」 |
| **约束** | 格式/长度/禁止项 | 「只输出译文，不要解释」 |
| **输入** | 待处理内容 | 用户给的段落 |

可写在 `system` 里（规则），`user` 里（具体文本）。

---

## 5 种 Prompt 练习

用 `exercises/day09/prompt_lab.py` 或直接改 `chat.py` 的 `messages` 测试。

### 1. 翻译 Translation

```
system: 你是专业翻译。只输出译文，不要解释。
user:   把下面中文翻译成英文：今天天气不错，适合出去散步。
```

### 2. 摘要 Summary

```
system: 你是摘要助手。用不超过 50 字概括下面文章要点。
user:   （粘贴一段 200 字左右新闻/产品介绍）
```

### 3. 分类 Classification

```
system: 你是文本分类器。只输出一个标签：正面 / 负面 / 中性。不要解释。
user:   这家餐厅的服务员态度很好，但等位太久了。
```

### 4. 提取 Extraction

```
system: 你是信息提取助手。从文本中提取：姓名、公司、职位。用 JSON 格式输出。
user:   张三目前在字节跳动担任算法工程师。
```

### 5. 生成 Generation

```
system: 你是 Python 助教。根据用户需求生成一段简短示例代码，并加一行注释。
user:   写一个函数，判断字符串是否为回文。
```

## Few-shot（了解即可，D10 会深入）

在 Prompt 里给 1～2 个「输入→输出」示例，模型更容易照格式做：

```
user:
分类示例：
输入：物流很快 → 正面
输入：质量太差 → 负面
输入：这家餐厅的服务员态度很好，但等位太久了。 →
```

2 小时版可先不做；有余力在「分类」或「提取」上试一条。
